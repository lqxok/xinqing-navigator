# 华农心晴导航 · 校园心理健康智能助手

基于 **Dify Advanced Chat** 编排的校园心理健康对话智能体。

核心不是「能聊天」，而是 **先保安全、再谈体验**：在模型开口之前，先用**确定性的规则链路**完成危机识别、风险分级与流程分流。

本仓库是该工作流的 **Dify 导出文件（DSL）**，可直接导入 Dify 复现整套编排。

---

## 为什么做

校园心理支持场景里，「答得好不好」是次要问题，**「出事前的风险识别与转介」才是第一位**。因此本项目把安全判断放在链路最前面，并尽量用**确定性代码**（而非让模型自由发挥）来兜底。

---

## 整体链路

```
用户输入
 └─ 输入隐私脱敏 (code)                        ← 第一层 PII 脱敏
     └─ 模型前状态路由 / 确定性分流 (code, if-else)
         └─ 安全与能力预检路由 (if-else)
             ├─ 命中危机 → 分级标签 + 温暖回复 / 温和转介 / 他人风险应对 / 危机术语解释
             └─ 未命中 → 意图识别 (llm) → 意图路由 (if-else)
                  ├─ 知识检索 (knowledge-retrieval) → 统一对话 (llm) → 对话回复
                  ├─ 校园服务 (llm) → 校园服务回复
                  ├─ 校园公告识图 (llm, 多模态) → 识图结果回复
                  └─ 量表类：GAD-7 / 性格偏好 / 心情打卡 → 逐题状态机 (code) → 对应回复
         └─ 记忆提取 (llm, 可兜底)
              └─ 记忆 JSON 解析与二次脱敏 (code)   ← 第二层 PII 脱敏
                   └─ 记忆变量赋值 (assigner)
```

---

## 几个关键设计

### 1. 安全前置（Safety-first）

安全判断不交给模型，而是走在最前面：
- **危机预检路由**先识别自杀 / 自伤 / 伤人风险，命中即打**分级标签**（即时风险 / 高风险）
- 命中后走**温暖回复 + 温和转介**话术，并支持**他人风险**（"我朋友想不开"）与**服药语境澄清**等细分场景
- **确定性守卫**兜住模型误判：确认安全后关闭重复追问，避免对已澄清的用户反复盘问

### 2. 两层 PII 脱敏

- **第一层**：用户输入进入链路前先脱敏（`输入隐私脱敏`）
- **第二层**：记忆写入 / 读取时对 JSON 再脱敏（`记忆JSON解析与二次脱敏`）

避免手机号、学号等敏感信息被写进会话记忆或透传给模型。

### 3. 可恢复状态机

GAD-7 焦虑量表、性格偏好测试、快速心情打卡三类交互式测评，全部用 **Python 代码节点**实现状态机，支持**逐题推进 / 回退 / 修改 / 查看 / 退出**，并把进度与等级写入会话变量，中断后仍可继续。

### 4. 确定性兜底

意图识别、记忆提取等 LLM 节点均标注「可兜底」；各分支都配有专用兜底回复（系统兜底 / 校园服务兜底 / 识图失败兜底），避免模型异常时链路断掉。

## 节点构成

| 类型 | 数量 | 作用 |
|---|---|---|
| `start` | 1 | 入口 |
| `if-else` | 3 | 路由分流（安全路由 / 意图路由 / 模型前分流） |
| `llm` | 5 | 意图识别、统一对话、记忆提取、校园服务、公告识图 |
| `code` | 16 | 脱敏、状态机、确定性守卫、时间获取等确定性逻辑 |
| `assigner` | 8 | 写入会话变量（危机标签、量表进度等） |
| `answer` | 19 | 各类回复出口 |
| `knowledge-retrieval` | 1 | 校园知识库检索 |
| **合计** | **53** | 68 条连线、15 个会话变量 |

---

## 如何使用

1. 打开 Dify（自建或云端），进入「工作室」
2. 新建应用 → **导入 DSL 文件** → 选择本仓库的 `workflow.yml`
3. 配置模型供应商：工作流使用 **OpenAI 兼容接口**，具体模型见各 LLM 节点
4. 绑定校园知识库后即可对话

> 本仓库**不包含任何密钥**。模型供应商与知识库需自行配置。
